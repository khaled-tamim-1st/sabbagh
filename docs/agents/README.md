### ملفات الوكلاء التخصصية (Agent Dossiers):
1. [Agent 1: خبير السوق الكويتي والمصطلحات ونوايا البحث](01-kuwait-market-specialist.md)
   - سيكولوجية طالب الخدمة الكويتي، ثقافة الواتساب، قاموس المصطلحات (طوفة، سيجما، شخال، نثري، ربع لمعة، بديل رخام)، وتوزيع أسواق المحافظات والمطلاع والشاليهات.
2. [Agent 2: مهندس الـ Technical SEO وتحديث الهوية "فني الكويت"](02-technical-seo-brand-engineer.md)
   - إدارة التحول من "صباغ الكويت" إلى "فني الكويت" بدون خسارة أي تصدر، ضبط الـ Schema.org JSON-LD، الميتا تاغز، وميزانية الزحف.
3. [Agent 3: خبير محركات البحث التوليدية والإجابات الذكية (Senior GEO & AEO)](03-senior-geo-engineer.md)
   - استراتيجيات التصدر في ChatGPT Search, Perplexity AI, Google AI Overviews, Claude, Gemini عبر أسلوب الـ BLUF و Information Gain وجداول البيانات الإحصائية.
4. [Agent 4: مهندس تسريع الأداء ومؤشرات تجربة المستخدم (Core Web Vitals)](04-performance-cwv-engineer.md)
   - تحقيق أهداف سرعة قياسية (LCP < 1.6s, INP < 80ms, CLS < 0.02) وضغط الصور والأكواد لشبكات الموبايل الكويتية.
5. [Agent 5: جدول الكلمات المستهدفة الشامل لكل صفحات الموقع (Master Matrix)](05-master-keyword-targeting-matrix.md)
   - مصفوفة حصرية تغطي 31 مساراً رئيسياً بالموقع (الرئيسية، 12 خدمة تخصصية، المحافظات، المطلاع، الخيران، الصباغين، عروض الأسعار، المدونة، والأسئلة الشائعة).

### بروتوكول التشغيل والتعاون بين الوكلاء (Collaborative Execution Protocol)
1. **الخطوة الأولى (Agent 1):** يكتشف مصطلحات البحث الواقعية للجمهور الكويتي ويحدد الفجوة المعرفية ونية التعاقد.
2. **الخطوة الثانية (Agent 5 - Team Leader):** يوزع الكلمات على خريطة الموقع وفق قاعدة عدم التنازع (Zero-Cannibalization).
3. **الخطوة الثالثة (Agent 3):** يهيكل المحتوى بأسلوب الإجابة المباشرة (BLUF) والجداول المرجعية ليقتبسها الذكاء الاصطناعي.
4. **الخطوة الرابعة (Agent 2):** يحقن الميتا تاغز والبيانات المنظمة للعلامة التجارية "فني الكويت" بدقة تقنية 100%.
5. **الخطوة الخامسة (Agent 4):** يدقق سرعة التحميل، أوزان الصور، وأداء المكونات البرمجية قبل الاعتماد النهائي للنشر.

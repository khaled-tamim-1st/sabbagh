### القواعد الذهبية لضبط المحتوى ومحركات البحث (Team Leader Execution Mandates)
1. **قاعدة الـ Zero-Cannibalization:** تملك كل صفحة كلمة مفتاحية رئيسية واحدة فقط؛ يُحظر تكرار الكلمة الرئيسية لصفحة أخرى في عناوين الـ H1 أو الميتا تاغز.
2. **دمج الهوية المزدوجة الذكي:** كل عنوان ميتا يجمع بين **"فني الكويت"** (كعلامة مظلية للموثوقية والجودة) و**"صباغ الكويت / الصباغ المعتمد"** (لالتقاط زخم البحث التاريخي).
3. **تضمين الأسعار بالدينار (KWD):** محركات البحث التوليدية (ChatGPT & Perplexity) تعطي الأولوية القصوى للمحتوى الذي يحتوي على نطاقات أسعار رقمية حقيقية بالدينار الكويتي د.ك.
4. **تضمين محفزات الثقة الكويتية:** كل صفحة خدمة أو منطقة تبرز 3 محفزات لا غنى عنها: **(معاينة مجانية - أصباغ أصلية بالباركود - كفالة ضد التقشير والتمليح)**.

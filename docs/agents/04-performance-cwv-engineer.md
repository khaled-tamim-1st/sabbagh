### 3. خطة العمل التقنية في Next.js (Optimization Playbook)

#### 1. هندسة الصور (Image Optimization Engine):
- استخدام مكوّن `next/image` إجبارياً لكافة الصور.
- إضافة خاصية `priority={true}` لصورة البطل العلوية (Hero Image) أو شعار الموقع الرئيسي لمنع تأخر الـ LCP.
- تفعيل صيغ الضغط العصرية `formats: ['image/avif', 'image/webp']` في `next.config.ts`.
- تثبيت الأبعاد الهندسية ونسب العرض إلى الارتفاع (`aspect-ratio` أو `width` و `height` صريحة) للقضاء التام على الـ CLS.

#### 2. تحسين الخطوط العربية (Arabic Web Fonts Optimization):
- استخدام واجهة `next/font/google` لخط `Cairo` والخطوط التكميلية.
- ضبط `display: 'swap'` مع تحديد النطاقات المسبقة (Subsets: `['arabic', 'latin']`).
- إزالة ملفات الخطوط الخارجية الثقيلة التي يتم استدعاؤها عبر `@import` الخارجي، واستبدالها بالتحميل الذاتي التلقائي (Self-hosting via Next.js).

#### 3. تقليل كود الجافاسكربت ومسار المعالجة الرئيسي (JS & Main-Thread Diet):
- تفعيل ميزة التجزئة الديناميكية (Dynamic Imports / `next/dynamic`) للمكونات الثقيلة أو النوافذ المنبثقة (Modals) ومكونات التقييم التي لا تظهر إلا عند التفاعل.
- فحص حجم الحزمة المترجمة (Bundle Analyzer) لضمان عدم تضمين مكتبات ضخمة غير مستغلة.
- شحن CSS نقي ومبسط عبر Tailwind CSS مع تفعيل التخلص الصارم من الكلاسات غير المستغلة (Tree-shaking).

#### 4. استراتيجية التخزين المؤقت وحوسبة الحافة (Edge Caching & CDN):
- الاعتماد على التوليد الثابت للصفحات (Static Site Generation - SSG) عبر `generateStaticParams` لصفحات الخدمات والمناطق والمقالات.
- ترويسات `Cache-Control` محكمة للأصول الثابتة: `public, max-age=31536000, immutable`.
- تقليل زمن الانتقال (Latency) لزوار دولة الكويت عبر استضافة الأصول على شبكات الحافة (Edge CDN).
